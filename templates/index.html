Sync Secrets

Back up SSH keys, Git config, environment variables, and more. Encrypted and uploaded to Cloudflare R2 — restore on any machine.

⚡ Quick Connect

Paste your Cloudflare API token and we'll auto-configure everything — bucket, credentials, the works.

Where do I get an API token? ▾
1
Create a Cloudflare API Token

Go to My Profile → API Tokens → Create Token → Create Custom Token. Set permission to Account → Workers R2 Storage → Admin Read & Write. This lets WinTools create a bucket and read/write your backups.

Create API Token →
2
Copy the token value

After creating the token, Cloudflare shows the token value once. Copy it — this is what you paste above.

⚠ The token value is only shown once. Copy it before leaving the page!
3
Paste & click Connect

We'll verify the token, create an R2 bucket (if needed), derive S3 credentials, and auto-fill the form below. Your token is never stored — it's used once during setup only.

Or Enter R2 Credentials Manually

If you already have R2 Access Key ID and Secret Access Key, enter them here.
